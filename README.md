# Student Management System

A Student Management System application built in two distinct implementation phases: Vanilla TypeScript and React with TypeScript using Vite.

## Tech Stack
- TypeScript
- React
- HTML5 & CSS3
- Vite

## Project Architecture
- `vanilla-ts/`: Pure TypeScript implementation covering DOM manipulation, type definitions, interface contracts, and client-side filtering.
- `react-ts/`: Component-based React implementation featuring modular structure, local storage persistence, state handling, and full CRUD workflows.

## Features
- **Student Data Modeling**: Strongly typed entities with name, email, age, department, status, and optional contact fields.
- **Search & Filter**: Real-time name search with multi-criteria filtering by department and active status.
- **CRUD Workflows**: Capabilities to add, view, update, and remove student profiles.
- **Local Persistence**: Client-side storage retention across sessions.
- **Real-Time Analytics**: Dynamic metric counters tracking total, active, and inactive students.

## How to Run Locally

### 1. Vanilla TypeScript
Navigate to the directory and run:
npm install
npm run dev

### 2. React + TypeScript
Navigate to the directory and run:
npm install
npm run dev
